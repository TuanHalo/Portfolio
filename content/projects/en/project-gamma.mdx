## Overview

This very site: a static bilingual portfolio with a Bento-grid homepage, automatic A4 resume PDF generation via Playwright, and an AI-friendly content contract.

## Key Features

- **Strict Zod schemas** for every content collection.
- **EN + VI routing** with automatic fallback notices for untranslated entries.
- **Full-text search** indexed per language with Pagefind.
