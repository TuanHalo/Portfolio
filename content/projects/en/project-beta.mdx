## Overview

Project Beta is a fast command-line validator written in Go that catches misconfigured environment variables and Docker compose port conflicts before CI runs.

## Highlights

- **Zero runtime dependencies**: Ships as a single static binary for Linux, macOS, and Windows.
- **Structured diagnostics**: Outputs `file:line: rule-id` errors compatible with GitHub Actions annotations.
