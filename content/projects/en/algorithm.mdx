## Overview

`Algorithm Hub` is an algorithm study site and problem-solving journal built with Astro and TypeScript, using interactive visualizations and a Claymorphism UI to walk through core algorithms and interview problems.

## What's inside

The teaching section (`/learn/`) is organized around 10 core topics. Sorting and Searching already have interactive lessons with step-by-step simulations, Python implementations, comparison tables, and complexity breakdowns. Graph, Dynamic Programming, Tree, Linked List, Stack & Queue, Hashing, Greedy, and Backtracking have topic roadmaps in place.

The problem journal (`/problems/`) collects LeetCode and HackerRank write-ups with my approach, solution code, edge cases, and AI-assisted review notes.

## Architecture and approach

A custom Astro integration (`src/integrations/visualizers`) bundles standalone sorting and searching visualizers directly into the static build. Generated Archify diagrams (`public/diagrams/`) trace the execution flow for Binary Search, Quick Sort, Merge Sort, Heap Sort, and Two Sum. The site runs on Astro 5 with Shiki syntax highlighting and deploys to GitHub Pages.
