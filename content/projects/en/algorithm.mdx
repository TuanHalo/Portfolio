## Overview

`Algorithm Hub` is an interactive learning platform and personal problem-solving journal built with Astro and TypeScript, designed to make core algorithms and coding interview problems visual and approachable through a Claymorphism UI.

## What's Inside

- **Teaching Hub (`/learn/`)**: Organized across 10 core algorithm topics—with interactive lessons, step-by-step simulations, Python implementations, comparison matrices, and complexity breakdowns already live for **Sorting** and **Searching**, and structured topic roadmaps ready for **Graph**, **Dynamic Programming**, **Tree**, **Linked List**, **Stack & Queue**, **Hashing**, **Greedy**, and **Backtracking**.
- **Problem Journal (`/problems/`)**: Structured write-ups for LeetCode and HackerRank problems documenting my approach, solution code, edge cases, and AI-assisted review notes.

## Architecture & Approach

- **Custom Visualizer Integration**: Built a dedicated Astro integration (`src/integrations/visualizers`) that bundles standalone interactive sorting and searching visualizers directly into the static output.
- **Workflow & Dataflow Diagrams**: Embedded generated Archify diagrams (`public/diagrams/`) to trace execution flow for algorithms like Binary Search, Quick Sort, Merge Sort, Heap Sort, and Two Sum.
- **Static & Fast**: Powered by Astro 5, Shiki syntax highlighting, and automated static deployment to GitHub Pages.
