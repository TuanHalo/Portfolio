## Overview

`AI-Usage` is my single source of truth for authoring, validating, and distributing AI coding assets—including skills, rules, agent personas, and engineering principles—while publishing an interactive Claymorphism documentation hub and deliverable reports on GitHub Pages.

## The Problem

Using multiple AI coding assistants (`Antigravity`, `Cursor`, `Claude Code`, and `Gemini CLI`) meant duplicating instructions across incompatible global config formats and paths. Keeping standards, style guides, and workflows consistent by hand quickly drifted out of sync.

## Architecture & Approach

- **Canonical Authoring**: Skills, rules, agents, and principles live once under `assets/` in structured Markdown and YAML.
- **Declarative Contracts**: `content-contract.yaml`, `style-contract.yaml`, and `output-contract.yaml` paired with JSON Schemas enforce consistent structure and token limits.
- **Multi-Tool Sync Engine**: A PowerShell orchestrator (`scripts/sync.ps1`) with per-tool transforms and `-DryRun` / `-ValidateOnly` modes maps assets to each tool's native format (`SKILL.md`, `AGENTS.md`, `.mdc`, `CLAUDE.md`, `GEMINI.md`).
- **Automated Docs Site**: An Astro 5 site under `site/` with a Claymorphism design system bundles deliverables and deploys to GitHub Pages via GitHub Actions.
