## Overview

`AI-Usage` stores and validates my AI coding assets (skills, rules, agent personas, and engineering principles) in one repository, syncs them to each tool I use, and publishes a Claymorphism documentation site and deliverable reports on GitHub Pages.

## The problem

Using `Antigravity`, `Cursor`, `Claude Code`, and `Gemini CLI` side by side meant copying the same instructions into different config formats and paths. Updating them by hand quickly left the tools out of sync.

## Architecture and approach

All skills, rules, agents, and principles live once under `assets/` in Markdown and YAML. To keep structure and token limits consistent, `content-contract.yaml`, `style-contract.yaml`, and `output-contract.yaml` pair with JSON Schemas during validation.

A PowerShell script (`scripts/sync.ps1`) converts those files into each assistant's native format (`SKILL.md`, `AGENTS.md`, `.mdc`, `CLAUDE.md`, and `GEMINI.md`), with `-DryRun` and `-ValidateOnly` flags for safe checks before writing. An Astro 5 site under `site/` then packages the documentation and deliverable reports using a Claymorphism design system and deploys to GitHub Pages via GitHub Actions.
