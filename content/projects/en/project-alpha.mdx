## The Problem

Teams needed a fast way to inspect real-time usage metrics across dozens of workspaces without waiting several seconds for heavy SQL aggregations on every page load.

## Architecture & Approach

- **Typed API Layer**: Shared Zod schemas between backend handlers and frontend hooks eliminated contract drift.
- **Query Batching**: Coalesced concurrent dashboard widget queries into a single round trip.
- **Incremental Caching**: Pre-aggregated hourly rollups in PostgreSQL kept p95 latency under 120ms.

## Outcome

- Served **40,000+ monthly active users** with zero downtime during peak traffic.
- Cut p95 API response time by **38%**.
